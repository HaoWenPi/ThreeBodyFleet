# 自然选择号 · 深空航行模拟

一个基于 Three.js 的单页 3D 舰队航行模拟。驾驶「自然选择号」旗舰与 11 艘僚舰，切换推进档位，在「前进四」进入 0.10c 跃迁；也可进入单人「舰队战役 · 战术推演」，以舰队司令身份指挥炮塔与僚舰迎战三体宇宙的敌对信号。

**纯静态、零后端、无需登录；本地运行时完全离线。** 所有依赖都在仓库里，双击 `index.html` 即可离线运行。

- 在线试玩：https://www.workbuddy.link/p/Ipkm3BuUttxgpr9CywzevY
- 当前程序版本：**v1.2.2**（HUD 左上角「舰籍信息」面板显示；模型包自身的 `1.0.0` 与之独立）
- 许可证：Apache-2.0，见 [LICENSE](LICENSE)
- 版本变更记录：[changelog.md](changelog.md)

> 演示数值为游戏化设定，非原著设定。

## 快速开始

### 方式一：在线玩（最快）

打开上面的公开链接即可，手机浏览器直接可玩，无需注册。首屏是**混沌平面牛顿三体**加载圈：三颗等质量球体只受彼此的点质量万有引力，每一对力严格满足牛顿第三定律，由 velocity Verlet 辛积分（近距遭遇时自动细分子步）在二维平面实时推进；初值已离开八字周期解的稳定岛，轨道永不闭合，且球体的大小、亮度与拉伸随瞬时速度变化，能直接看出忽快忽慢。点击圈体或「进入舰桥」即可开始；模型数据读入期间由纯 CSS 圆周运动兜底，`app.js` 就绪后平滑切换到引力轨道。开场层刻意保持简洁，完整键位见下方「操作」或游戏内按 `H`。

> 物理口径：`G = m = 1`，宏观步长 `dt = 0.0025`（按最小间距的特征时间 `r^1.5` 拆成 1–32 个子步，总时间仍严格为 `dt`，因此无需引力软化）；初值在八字解基础上令 `v3.x += 0.10`、`v1/v2` 各 `-= 0.05`，**总动量与质心仍恒为 0**，`T = 6.32591398` 此时只作时间标尺而非周期。独立数值实验：八字解受 `1e-6` 微扰后分离度仅 `5e-4`（线性稳定），本版初值在 `t = 240` 时分离度 `5845`；段内速率浏览器实测 `0.455 → 1.677`（3.68 倍，旧周期解 2.72 倍；独立 Python 段实验为 4.1 倍），状态离初值的最小回归距离 `0.239`（旧 `0.016`）。真混沌三体终会抛射一球，故按段播放：每段先静默预推进到不同相位，再显示 75 个物理时间（v1.0.6 播放速率下约 35.6 s），8 段循环、段间 0.55 s 插值重投；**段内 100% 物理，段间重投是明确的视觉兜底**。渲染只做「整体旋转 45° + 等比缩放」的正交变换，中心光核即恒定质心。画面只有 3 颗球体与圆心质心光核，不绘制任何尾迹小点。

> 播放速率：v1.0.6 把标称「一圈」由 2.15 s 调慢到 **3.0 s**（单一常量 `LOOP_S`），每秒推进的物理时间由 2.9423 降到 2.1086（**慢约 28%**）。只缩放时间流速，`dt`、混沌初值、段长、速度→尺寸/亮度/拉伸映射与物理函数块全部未改；纯 CSS 首屏兜底同步为 3 s，系统开启「减弱动态效果」时为 8.6 s。

### 方式二：本地离线运行（推荐给开发者）

1. 克隆仓库或下载 zip 并解压：

   ```bash
   git clone git@github.com:HaoWenPi/ThreeBodyFleet.git
   ```

2. 确认以下文件与目录保持原有相对位置（不要只拷贝 `index.html`）：

   ```
   index.html
   app.js
   style.css
   vendor/three.min.js
   ship-model.js
   models/NaturalSelection-Structured/ship-structured.js
   ```

3. **双击 `index.html`**。

不需要 `npm install`、不需要构建、不需要起服务器、不需要数据库。`file://` 下即可运行，断网也能玩。

### 方式三：起一个静态服务（可选）

若习惯用 `http://` 打开（例如要调试 Service Worker 或做真机局域网测试）：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。服务只负责分发静态文件，本身不含任何业务逻辑。

**浏览器要求**：支持 WebGL 的桌面或移动浏览器。Three.js r150 已随仓库放在 `vendor/three.min.js`，无需 CDN。若 WebGL 不可用，页面会显示明确提示而不是白屏。

## 舰队战役（四关可玩版）

以「舰队战术推演系统」为框架：你在模拟舱中重演人类面对三体探测器的经典战役，
**不改写原著正史结局**，因此可反复重开。**四关战役已全部开放**：任务 01「接触 · 智子盲区」
（全歼 4 波 13 架敌舰）→ 02「末日战役 · 水滴」（护送僚舰撤离，水滴不可击毁）→
03「猜疑链 · 黑暗战役」（生存 68 s）→ 04「引力波广播 · 守卫」（守卫 62 s 后按 `4` 跃迁撤离）。
工具栏 `◈` 从任务 01 开始，`▤` 打开任务列表选关；通关自动解锁下一关，进度存在本机
`localStorage`（不可用时降级为会话内有效）。任务 02–04 开场有剧情字幕，可点「跳过字幕」。
所有数值为游戏化设定，非原著设定。

### 四关规则速查

| 任务 | 胜利条件 | 失败条件 | 关键提示 |
| --- | --- | --- | --- |
| 01 智子盲区 | 清除全部 4 波敌对信号 | 舰体归零 / 僚舰全灭 / 超过 150 s | 常规战斗，`Tab` 切目标、`空格` 发射 |
| 02 末日战役 · 水滴 | 撑过 72 s **且** 至少 6 艘僚舰存活 | 舰体归零 / 僚舰全灭 / 超过 110 s；72 s 时僚舰不足 6 艘也会失败 | 水滴**不可击毁**，且会逐一贯穿僚舰；`F` 环形护卫减伤、`B` 规避可擦过、降到前进一可拉开追猎距离 |
| 03 猜疑链 · 黑暗战役 | **无需歼灭**，生存到 68 s 计时结束 | 舰体归零 / 僚舰全灭 / 超过 100 s | 逃亡舰外形像僚舰，但雷达敌红我青；`B` 规避与 `F` 松散巡航可减压 |
| 04 引力波广播 · 守卫 | 守卫 62 s 后按 `4` 前进四跃迁撤离 | 舰体归零 / 僚舰全灭 / 超过 110 s | 倒计时结束前按 `4` 仍是「跃迁锁定」；18 s 后系统自动脱离兜底 |

规则同时写在**开场字幕卡**、**HUD 任务卡常驻规则条**（可展开打法提示）和**选关面板**三处。
任务 02 的 HUD 实时显示「僚舰 11/6 ✓ 达标」，不足时明确提示「✗ 不足 · 已无法达成撤离条件」，
不必干等到超时；锁定水滴时锁定卡会提示「⚠ 不可击毁 · 请勿浪费火力」。

### 水滴贯穿机制（任务 02）

水滴不再沿固定轨道绕圈发弹，而是**锁定一艘僚舰 → 高速贯穿 → 回环再追猎**，
并会持续追打同一艘直到它殉爆，才换下一艘：

| 阶段 | 表现 |
| --- | --- |
| 锁定 | 战报「水滴锁定 僚舰-01 · 高速贯穿」，银色探测器从接战距离外加速冲来，拖白青光轨 |
| 贯穿 | 该舰**直接扣 46% 完整度**（强相互作用力穿透能量护盾，只吃阵型减伤）；战报「水滴贯穿 僚舰-01 · 完整度 54%」 |
| 损毁 | 受损舰亮起橙红破口光核，越接近殉爆越红越亮，并持续冒火花；雷达与 HUD 仍显示它在列 |
| 殉爆 | 完整度归零 → 三层火球 + `WING DESTROYED` 提示 + 战报「僚舰-01 殉爆 · 水滴贯穿」，该舰从舰队消失 |
| 换目标 | 水滴回环后锁定下一艘（优先受损最重的），直到撤离窗口结束 |

`F` 环形护卫把单次贯穿降到 34.5%，并让回环冷却变长；`B` 规避有概率擦过；
降到前进一会把待机位拉远，减少 72 s 内的贯穿次数。实测正常操作下
水滴贯穿 10 次、殉爆 3 艘，剩余 8 艘仍能达标；完全不操作则会被普通敌弹击沉旗舰。

| 输入 | 作用 |
| --- | --- |
| `Tab` · 点「切目标」按钮 | 在存活敌舰间切换锁定目标 |
| `空格` · 点「发射」按钮 | 发射当前武器；默认能量炮为 6 座主炮齐射（冷却 2.4 s，弹丸自动分散到多个目标） |
| `X` / `Z` · 点武器卡 | 切换下一 / 上一件武器（能量炮 / 激光 / 鱼雷 / 离子炮，各自独立冷却） |
| `C` · 点「战术俯视」按钮 | 切换斜俯视战术机位；此模式下鼠标不再操舵，点击画面可点选敌舰 |
| `G` / `B` | 舰队指令：集火 FOCUS（伤害更高、僚舰还击更快）/ 规避 EVADE（降低敌弹命中） |
| `F` | 切换 5 套阵型并启用战术加成（环形护卫拦截 / 战列横队主炮 +25% / 松散巡航规避等） |
| `▤` · 结算面板按钮 | 打开任务列表选关 / 进入下一关 / 清除进度；`Enter` 胜利后直接进下一关 |
| 点雷达标记 | 直接指定锁定目标；雷达图例：**青色实心菱形 = 僚舰**、**红色实心圆 = 敌舰**、**红色空心菱形 = 第三关逃亡舰**、**黄环 = 当前锁定**。屏幕边缘另有橙色方位指示器标出视野外敌舰 |
| `4`（仅任务 04 广播完成后） | 前进四跃迁撤离，完成守卫关；提前按仍是「跃迁锁定」 |
| `Esc` | 退出战役回到自由航行；结算后 `Enter` 进入下一关（失败则重试本关） |

战斗在**开战瞬间锚定的世界空间**进行：敌舰、弹丸与爆炸是空间里独立存在的实体，
旗舰转向或镜头环绕只会看到它们相对滑动，不会跟着视角一起转；6 座炮塔另挂在跟随舰体的
挂载组下，保证炮口始终贴合舰体。星场仍流动但只乘一个视觉系数，因此敌人不会被背景一起冲走。

**档位会改变接战距离**：前进二是战斗巡航基准（16.5 千 km），切到前进三会主动接敌、
敌阵平滑逼近到约 13.5 千 km 且星流加速；减速或停车则脱离到约 19.5～22.5 千 km、星流放缓。
任务卡显示「接战距离」，锁定卡显示「相对 ±x.xxx c」，换档会记入战报。
`0`–`4` 档位在战役中仍可用，但「前进四」被锁定（接敌必须退出跃迁）；
`AHEAD` 梯度、四喷口与蓝焰视觉不受影响。

编队航向不再与旗舰姿态刚性绑定：旗舰改航向时 11 艘僚舰保留原航向惯性、被转弯离心侧偏甩开，
再按各自刚度 / 阻尼 / 转向速率走弧线归队，高速巡航时整队转向更迟钝。

**旗舰有巨舰惯性**：转向指令先经角速度低通（起转 0.42 s、松手余转 1.10 s），
按下后要慢慢起转、松开后还会继续滑行一小段才停，不再一帧定住。

**四种武器各有所长**：能量炮均衡、可分散打多目标；激光瞬时命中、射速最快但只打锁定目标；
鱼雷慢速重弹、命中有范围溅射；离子炮瘫痪目标武器与机动 4 秒。武器卡显示各自冷却，
`X` / `Z` 循环切换、点击武器卡直选，`空格` 发射当前武器。四者 DPS 大致相当，靠场景做取舍。

**指挥反馈**：屏幕边缘用橙色箭头 + 距离数字标出视野外的敌舰（锁定目标高亮），雷达标记可点选，
状态卡显示当前阵型加成与任务进度。任务卡常驻「胜利 / 失败」两行规则，点「展开打法提示」看细节；
同一份规则也写在开场字幕卡与选关面板上，字幕跳过后仍随时可查。第三关逃亡舰虽与僚舰外形相似，
雷达上始终标红，看图例即可分辨。
10 种程序化战斗音效（4 种武器 / 命中 / 爆炸 / 护盾 / 接敌 / 结算）复用既有 WebAudio 图，
不改动空灵气流环境音，也不新增资源文件；`M` 静音同样生效。

**能量护盾**：舰体外有一层程序化生成的青蓝色穹顶（fresnel 边缘辉光 + 网格 + 命中涟漪），
用 p=8 超椭球按真实舰体包围盒 8 个角点求半轴（K=1.18），完整罩住整艘舰；平时只留极淡轮廓，
受击时仅在命中方向显现一片并扩散涟漪，不会用常亮光罩挡住舰体。护盾先吸收伤害、溢出才伤舰体；脱战 3 秒后以 5.5%/s 回充，
被打破会进入 4 秒过载锁定并泛红。僚舰也各有 30 点护盾。状态卡显示护盾百分比、进度条与
「在线 / 充能中 / 过载 / 离线」状态。

敌舰血条与锁定框、弹道 / 光束、命中爆炸、护盾穹顶与命中涟漪、受击红闪、战报、雷达与结算面板共同构成
「看得见的战斗」。旗舰 6 座炮塔的硬点由真实舰体网格包围盒**运行时导出**，不硬编码坐标；
11 艘僚舰各有完整度、会受击失联。

## URL 参数

参数均加在页面地址后，用 `&` 组合。以下列表按源码实际读取行为整理，未列出的参数不生效。

| 参数 | 作用 | 示例 |
| --- | --- | --- |
| `orbit=<deg>` · `pitch=<deg>` | 以指定环绕角度开场，便于分享定格视角 | `?orbit=-75&pitch=10` |
| `autostart=1` | 跳过开场层，直接进入场景 | `?autostart=1` |
| `gear=<0-4>` | **仅在 `autostart=1` 时生效**，指定开场档位，缺省为 `2` | `?autostart=1&gear=4` |
| `instant=1` | **仅在 `autostart=1` 时生效**，立即到达目标速度 | `?autostart=1&gear=4&instant=1` |
| `formation=<0-4>` | 指定开场阵型 | `?formation=2` |
| `hull=glb` | 回退到上一代 GLB 舰体，用于对照 | `?hull=glb` |
| `normal=1` | GLB 模式下恢复高频 normalMap | `?hull=glb&normal=1` |
| `compact=1` / `compact=0` | 强制小屏折叠 / 完整 HUD | `?compact=0` |
| `yaw=0` | 关闭模型朝向翻转 | `?yaw=0` |
| `campaign=1` | 直接进入舰队战役任务 01 | `?campaign=1` |
| `roll=1` | 开场自动滚转 | `?roll=1` |

战役入口：`?campaign=1` 直接进入任务 01「接触 · 智子盲区」（会自动隐藏开场层）；也可点工具栏 `◈`。
退出战役按 `Esc`，即回到自由航行，航行状态不重置。

> `?zoom=` **不是**受支持的参数。缩放请用滚轮 / 双指捏合；`zoom` 在程序里表示「相机距离倍率」（越小画面越大），HUD 上显示的百分比是 `1/zoom`。

深链示例（本地或自建静态托管）：`index.html?orbit=-75&pitch=10&autostart=1&gear=4`

> 托管发布页是否向页面透传查询串取决于平台，本仓库未对此做保证；需要固定机位时建议用本地文件或自建静态托管打开。

## 舰体与素材

默认使用**结构化 STL 舰体**：源 STL 60,382 三角面 / 29,935 焊接顶点，按面划分为 10 个语义部位，配套 4 张 2048² atlas。上一代 GLB 舰体（约 15 万面、3 张 2048 WebP）可通过 `?hull=glb` 对照查看；结构化载荷缺失时会自动补载 GLB。

素材实况与绑定依据在 [交付说明](models/NaturalSelection-Structured/交付说明.md) 中如实记录：源 STL 本身**无 UV、无材质、无贴图**，5 张设计图是渲染参考图而非 UV 贴图，4 张 atlas 是依据设计图与 GLB 提取的 3 张原始 PBR 贴图**重建**的，并未伪装成原始贴图。素材权利以实际持有的授权为准，本仓库不额外声明。

`models/.../manifest.json` 里的 `version: 1.0.0` 是**模型包自身版本**，与程序版本 v1.2.2 相互独立。

## 开发

无构建步骤，改动后建议做静态检查：

```bash
node --check app.js
python tools/validate_bindings.py --root models/NaturalSelection-Structured
```

`validate_bindings.py` 会读真实 GLB accessor 与 PNG 做 22 项产物级校验（含反向验证），不只读 manifest。

页面暴露了一批只读诊断钩子，便于无头浏览器验证：`__NS_VERSION__` / `__NS_VIEW__` / `__NS_VIEW_STATE__` / `__NS_GESTURE__` / `__NS_BRIDGE__` / `__NS_MODEL_OK__` / `__NS_DRIVE__` / `__NS_FLAME__` / `__NS_CAM__` / `__NS_AUDIO__` / `__NS_NOZZLES__` / `__NS_NOZZLE_FX__` / `__NS_HULL_STRUCTURED__` / `__NS_COMBAT__` / `__NS_TURRETS__` / `__NS_FLEET__` / `__NS_ATTITUDE__` / `__NS_SHIELD__` / `__NS_CAMPAIGN__` / `__NS_SFX__` / `__NS_RADAR__` / `__NS_DROPLET__`。
`__NS_COMBAT__` 另提供 `start / salvo / cycle / toggleView / setOrder / selectWeapon(i) / advance(dt,n) / exit` 便于无头验证（同步推进战斗逻辑，不依赖 rAF）。

发版流程（语义化版本、git tag、GitHub 主仓库 + Gitee 镜像双推、云端发布态同步与一致性核验）见 [changelog.md](changelog.md) 的「维护约定」。

## 设计边界

这是**纯前端离线演示**：没有账号体系、没有积分系统、没有排行榜、没有后端服务，也不采集用户数据。页面运行时不发起任何 `fetch` / WebSocket / 接口请求。舰队战役同样完全在本机运行，敌人、炮塔与特效全部程序化生成，不新增资源文件；战役进度写入本机 `localStorage`（不可用时静默降级为会话内有效）。

仓库内的 `game-security-architecture.md` 是一份**已归档、未采纳**的历史设计稿，记录过「若将来要做账号与积分该怎么做」的评估过程，**不代表当前架构，也不是待办清单**。
